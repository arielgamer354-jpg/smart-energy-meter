INFORMASI PERANGKAT

Informasi Sistem

Informasi sistem monitoring konsumsi energi listrik.

Smart Energy Meter

Sistem Smart Energy Meter digunakan untuk melakukan monitoring konsumsi listrik secara real-time menggunakan teknologi Internet of Things (IoT).

Komponen Sistem
  • ESP32 sebagai mikrokontroler.
  • PZEM-004T sebagai sensor pengukuran listrik.
  • Wi-Fi sebagai media komunikasi.
  • Firebase Realtime Database sebagai media penyimpanan data.
  • Dashboard berbasis web sebagai media visualisasi.
Parameter yang Dipantau
  • Tegangan (V)
  • Arus (A)
  • Daya (W)
  • Energi (kWh)
